# Family Study Dashboard

Dashboard gia đình để bố/mẹ giao bài, quản lý lịch học và hai học sinh lớp 6/lớp 3 xác nhận hoàn thành.

## V1
- Bố/mẹ giao bài, deadline, mức độ ưu tiên.
- Hai màn hình riêng Lớp 6 / Lớp 3.
- Học sinh bấm xác nhận hoàn thành.
- Lịch học riêng từng con.
- Theo dõi chưa làm, hôm nay, quá hạn, đã xong.
- Responsive cho điện thoại và máy tính.

> V1 dùng localStorage nên dữ liệu chưa đồng bộ giữa các thiết bị. V2 sẽ nối cơ sở dữ liệu online (Firebase/Supabase) và phân quyền bố mẹ/học sinh.
